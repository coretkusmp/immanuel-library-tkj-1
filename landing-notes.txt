1. Apa keuntungan memisahkan header dan footer menjadi file component tersendiri, dibandingkan menuliskannya langsung berulang-ulang di index.php?
jawaban: Ketika ada bagian dari header ataupun footer yang ingin diubah maka bisa diubah di satu tempat saja tanpa mengubah di semua halaman. Jika tidak dimasukkan ke file component tersendiri maka kita harus menulis perubahan satu-satu ke dalam file yang berbeda-beda. Hal ini membuat memisahkan bagian header dan footer lebih efisien untuk waktu pengerjaannya.

2. Perhatikan halaman-halaman admin (Buku, Kategori, Penulis, Pengguna, Profil) pada Bagian 2 - bagian mana pada halaman-halaman tersebut yang mengalami masalah yang sama seperti header/footer sebelum dipisah?
jawaban: bagian sidebar. Bagian sidebar diisi ke beberapa halaman yang berbeda. Lebih baik membuat bagian sidebar di file component terpisah agar jika bagian sidebar ingin diubah, dapat terubah semuanya sekaligus.
